# Code of conduct

Discuss code and reasoning respectfully. Beginners are welcome, and missing knowledge is a reason to explain a step.

Do not harass, insult, threaten, discriminate against, or publish private information about others. Give people room to correct mistakes. Explain why a contribution needs changes and keep criticism focused on the work.

The maintainer may remove abusive content, close disruptive discussions, or restrict participation to keep the project usable.

To report a concern, open an issue without private details. If private handling is needed, ask the maintainer for a private contact method before sharing the incident. Do not post personal information in a public report.
